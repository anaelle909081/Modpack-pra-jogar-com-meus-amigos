O processo é bem simples:

1. Acesse o repositório e vá na seção Releases.
2. Clique com o botão direito sobre o arquivo da versão .mrpack desejada e selecione Copiar endereço do link.
3. Abra o Prism Launcher (ou PineconeMC).
4. Vá em Adicionar/Importar Instância, selecione a opção de importar via URL e cole o link copiado.
