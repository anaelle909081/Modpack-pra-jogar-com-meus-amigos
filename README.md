O processo é bem simples:

1. Acesse o repositório e vá até a seção Releases.
2. Clique com o botão direito sobre o arquivo da versão .mrpack desejada e selecione Copiar endereço do link.
3. Abra o Prism Launcher (ou PineconeMC).
4. Vá em Adicionar/Importar Instância, selecione a opção de importar via URL e cole o link copiado.

Sobre o modpack:

Este é um modpack com uma proposta Vanilla+, mantendo a essência do Minecraft original e sem alterar muito a gameplay. Adicionei alguns mods que gostei, buscando complementar e melhorar a experiência sem fugir do estilo vanilla.

O modpack também conta com Essential Mod e E4MC, permitindo jogar junto com os amigos de maneira mais fácil, sem precisar necessariamente criar um servidor dedicado.

O modpack é Server-side, ou seja, seus amigos também precisam instalá-lo para jogar junto com você. É importante que todos utilizem exatamente a mesma versão do modpack para evitar problemas de compatibilidade.
